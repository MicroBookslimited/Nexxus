Build a Super Admin Analytics & Usage Monitoring Dashboard for NEXXUS POS.

GOAL:
Allow MicroBooks/NEXXUS super admins to monitor client activity, resource usage, subscription health, plan limits, feature adoption, and Supabase cost risk before migration.

This module must answer:
- Which clients are active?
- Which clients are dormant?
- Which clients are using the most system resources?
- Which clients are close to plan limits?
- Which clients should be upgraded?
- Which clients may increase Supabase costs?
- Which features are actually being used?

--------------------------------------------------
1. ACCESS CONTROL
--------------------------------------------------

Create a Super Admin-only module.

Allowed:
- platform_super_admin only

Denied:
- tenant admin
- manager
- cashier
- staff
- reseller

Middleware:
authorizePlatformRole(['platform_super_admin'])

If unauthorized:
Return 403:
{
  "error": "ACCESS_DENIED",
  "message": "This dashboard is only available to platform super admins."
}

--------------------------------------------------
6. ACTIVITY SCORE
--------------------------------------------------

Calculate tenant_activity_score from 0 to 100.

Formula:
- Sales activity: 30%
- Login activity: 20%
- Inventory activity: 20%
- Report usage: 10%
- Staff usage: 10%
- Advanced feature usage: 10%

Labels:
- 80–100 = Very Active
- 50–79 = Active
- 25–49 = Low Activity
- 0–24 = Dormant

Advanced feature usage includes:
- multiple units
- volume pricing
- composite products
- sell by weight
- stock count
- stock variance reports
- staff clock-in
- Shopify integration
- Ding top-up
- online store

- storage_used_mb
- api_request_count
- realtime event volume
- auth_user_count
- file upload count
- sync volume
- webhook volume

Labels:
- 0–24 = Low
- 25–49 = Normal
- 50–69 = Watch

- 85–100 = Cost Risk
