Step 1 — Build ESC/POS plain text receipt string:

Format exactly as follows (42 chars wide for 80mm):

- Divider: full width dashes
- Order ref, timestamp, cashier, order mode, table (if dine-in)
- Divider
- Column header: item left-aligned, price right-aligned
- Each item: "{qty}x {name}" left-aligned, "{currency} {price}" right-aligned
- Pad lines to exactly 42 chars total using spaces
- Divider
- Subtotal right-aligned
- Tax ({taxRate}%) right-aligned — show "0.00" if zero
- Discount right-aligned — only show if discount > 0
- Divider
- "TOTAL: {currency} {total}" right-aligned, this line in CAPS
- Blank line
- Payment method right-aligned
- Amount Tendered right-aligned (only if cash)
- Change right-aligned (only if cash)
- Divider
- Address centered
- Phone centered
- Blank line
- "Thank you for your business!" centered
- "Powered by NEXXUS POS" centered
- 3 blank lines (paper feed before cut)

Step 2 — Fire to Looped Labs via intent URL:

function printViaLoopedLabs(receiptText) {
  // Encode the receipt text
  const encoded = encodeURIComponent(receiptText);
  
  // Build intent URL for Looped Labs
  // This opens the Looped Labs service and passes the text directly
  const intentUrl = [
    'intent:',
    '#Intent',
    'action=android.intent.action.SEND',
    'type=text/plain',
    `S.android.intent.extra.TEXT=${encoded}`,
    'package=com.loopedlabs.escposprintservice',
    'end'
  ].join(';');
  
  window.location.href = intentUrl;
}

IMPORTANT — if the intent approach does not work on the device, 
add a fallback using a URL scheme that Looped Labs also supports:
  escpos://print?text={encoded}
Try the intent first, fall back to the escpos:// scheme if needed.
Wrap in a try/catch and console.error any failures.

On desktop, inject a temporary hidden <div id="nexxus-print-receipt"> 
into the document body containing a clean HTML receipt, trigger 
window.print(), then remove the div immediately after.

The print-only receipt HTML must:
- Use inline styles only (no CSS class dependencies)
- Font: monospace, 12px
- Width: 80mm
- Include all receipt fields in the same order as ESC/POS above
- Use a <style> block with @media print rules that:
    * Hide everything on the page (body * { visibility: hidden })
    * Show only #nexxus-print-receipt and its children
    * Set page margin to 0
    * Set page size to 80mm wide

Function signature:
function printViaWindowPrint(order) {
  // 1. Build receipt HTML string
  const receiptHTML = buildReceiptHTML(order); 
  
  // 2. Create hidden container
  const container = document.createElement('div');
  container.id = 'nexxus-print-receipt';
  container.style.display = 'none';
  container.innerHTML = receiptHTML;
  document.body.appendChild(container);
  
  // 3. Inject print styles
  const style = document.createElement('style');
  style.innerHTML = `
    @media print {
      body * { visibility: hidden !important; }
      #nexxus-print-receipt,
      #nexxus-print-receipt * { visibility: visible !important; }
      #nexxus-print-receipt {
        display: block !important;
        position: absolute;
        left: 0; top: 0;
        width: 80mm;
        font-family: monospace;
        font-size: 12px;
        color: black;
      }
      @page { margin: 0; size: 80mm auto; }
    }
  `;
  document.head.appendChild(style);
  
  // 4. Print
  window.print();
  
  // 5. Cleanup after print dialog closes
  setTimeout(() => {
    document.body.removeChild(container);
    document.head.removeChild(style);
  }, 1000);
}
