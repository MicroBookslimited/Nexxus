Build a Shopify integration module for NEXXUS POS.

GOAL:
Allow NEXXUS POS businesses to connect their Shopify website so products, inventory, customers, and online orders can sync between Shopify and NEXXUS.

IMPORTANT CONTEXT:
Shopify supports Admin API and webhooks for product, order, customer, and inventory workflows. Shopify API versions change regularly, so build this integration using configurable API versioning and avoid hardcoding deprecated endpoints. Use Shopify GraphQL Admin API where practical. Shopify webhooks can be used to notify NEXXUS when orders, products, or inventory changes happen. Shopify documentation notes that webhooks send event payloads to HTTPS URLs. Shopify also releases API versions regularly, so versioning must be handled carefully.

--------------------------------------------------
3. PRODUCT SYNC
--------------------------------------------------

Allow products to sync between Shopify and NEXXUS.

Product fields to map:
- name/title
- SKU
- barcode
- description
- category/product_type
- price
- cost if available
- image URL
- active/status
- variants
- inventory tracking status

Rules:
- Match products using SKU first.
- If SKU is missing, use barcode.
- If neither exists, create as unmatched and flag for review.
- Prevent duplicate product creation.
- Support Shopify variants as NEXXUS product variants where applicable.

Admin UI:
- Sync Products Now button
- View mapped products
- View unmapped products
- Resolve mapping manually

--------------------------------------------------
4. INVENTORY SYNC
--------------------------------------------------

Support inventory syncing by location.

Rules:
- NEXXUS stock should remain the operational source of truth unless admin selects Shopify as source.
- If NEXXUS is source of truth:
    - When POS sale reduces stock, update Shopify inventory.
    - When stock count or purchase increases stock, update Shopify inventory.
- If Shopify is source of truth:
    - Shopify inventory updates should update NEXXUS stock.

Must support:
- Shopify inventory item IDs
- Shopify location IDs
- NEXXUS location IDs
- multi-location mapping

Important:
NEXXUS should maintain its own inventory movement ledger. Do not rely only on Shopify history.

--------------------------------------------------
5. ORDER SYNC
--------------------------------------------------

When an order is placed on Shopify:
- Receive webhook or pull order from Shopify
- Create online order in NEXXUS
- Deduct inventory in NEXXUS based on mapped products
- Mark order source as "Shopify"
- Store Shopify order ID and order number

NEXXUS order statuses:
- pending
- paid
- processing
- fulfilled
- cancelled
- refunded

Shopify order events to support:
- order created
- order paid
- order fulfilled
- order cancelled
- order refunded

If product is not mapped:
- Create order with warning
- Flag unmapped item
- Do not silently fail

--------------------------------------------------
6. CUSTOMER SYNC
--------------------------------------------------

When Shopify order includes customer:
- Match customer by email or phone
- If not found, create customer in NEXXUS
- Store Shopify customer ID

Customer fields:
- first name
- last name
- email
- phone
- address
- order history link

7. WEBHOOKS
--------------------------------------------------

Create webhook endpoints:

POST /webhooks/shopify/orders-create
POST /webhooks/shopify/orders-paid
POST /webhooks/shopify/orders-cancelled
POST /webhooks/shopify/orders-refunded
POST /webhooks/shopify/products-update
POST /webhooks/shopify/inventory-levels-update

Security:
- Verify Shopify webhook HMAC signature.
- Reject invalid signatures.
- Log all webhook requests.
- Make webhook handling idempotent.
- Prevent duplicate order imports.
