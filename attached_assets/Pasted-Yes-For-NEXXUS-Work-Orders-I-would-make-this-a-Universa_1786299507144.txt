Yes. For NEXXUS Work Orders, I would make this a Universal IT & Low-Voltage Installation Work Order rather than separate templates for every type of job. The technician selects the applicable service areas—Networking, POS, Access Control, PC/IT, CCTV, etc.—and the form dynamically exposes the relevant sections.

The objective is that this one template can handle everything from installing one PC to a 20-station POS deployment with networking, access control and security infrastructure.

2. Customer & Site Information

Capture customer/business name, primary contact, telephone, WhatsApp, email, billing address, service address, GPS/location, site contact, site contact telephone, branch/location name, opening hours, access instructions, parking information and any special site restrictions.

Include quick actions for Call, WhatsApp, Email and Directions in NEXXUS FSM.

3. Service Scope

Allow one or multiple service types on the same work order.

* POS Installation: POS terminal, touchscreen, customer display, receipt printer, cash drawer, barcode scanner, scale, kitchen printer, label printer, payment terminal, software installation, NEXXUS configuration, database/product setup, receipt configuration and user training.
* Networking: Router, firewall, switch, PoE switch, access point, structured cabling, patch panel, rack, network outlet, cable termination, VLAN, DHCP, static IP, Wi-Fi, internet testing, network printer and network documentation.
* PC & IT: Desktop, laptop, workstation, monitor, printer, UPS, Windows installation, drivers, updates, antivirus, Microsoft Office, user accounts, domain/workgroup, shared folders, backup, email, software installation and data migration.
* Access Control: Door controller, biometric reader, card reader, facial recognition terminal, magnetic lock, electric strike, exit button, emergency break glass, power supply, door contact, access cards, users, schedules, permissions and mobile/web configuration.
* CCTV / Security: IP/analog camera, NVR/DVR, hard drive, PoE, cabling, camera positioning, recording configuration, remote viewing and testing.
* Other: Custom installation, repair, maintenance, site survey or technical service.

22. Automatic Completion Report

Once signed, NEXXUS should generate a professional PDF containing the work-order number, customer/site details, scope of work, equipment installed, serial numbers, network summary, POS stations, PCs, access-control doors, parts used, labour, before/after photos, outstanding issues, technician notes, training completed and both signatures.

The completed report should automatically attach to the NEXXUS Web work order and be available from NEXXUS FSM.

One important addition

I would make this template conditional rather than showing everything to every technician. At the beginning of the work order, the dispatcher checks POS + Networking + Access Control, for example, and FSM automatically builds the technician’s checklist from those sections. That gives you one extremely comprehensive master template without forcing a technician doing a simple PC installation to scroll through 100 irrelevant CCTV and access-control questions.

This could effectively become the default NEXXUS “Technology Installation & Commissioning” template and cover the majority of MicroBooks field projects.
